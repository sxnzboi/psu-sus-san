⚠️ ต้องตั้งค่า Firebase ก่อน

ระบบนี้ใช้ Firebase Firestore เพื่อ sync ข้อมูลระหว่างเครื่อง คุณต้องใส่ Firebase Config ก่อนใช้งาน

วิธีตั้งค่า (15 นาที):

  1. เข้า console.firebase.google.com ลงชื่อด้วย Google account
  2. กด "Add project" → ตั้งชื่อ project
  3. เปิด Firestore Database → Create database → Test mode → asia-southeast1
  4. ไปที่ Project Settings → Your apps → Web app (icon </>) → คัดลอก firebaseConfig
  5. เปิดไฟล์ psu-sus-handover.html ด้วย Notepad/VS Code
  6. หาคำว่า FIREBASE_CONFIG_HERE
  7. แทนที่ firebaseConfig ด้วย config ของคุณ บันทึก แล้ว refresh เพจ

ดูคู่มือเต็มใน SETUP_FIREBASE.md
